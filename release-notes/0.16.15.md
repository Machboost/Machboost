# MachBoost 0.16.15

This release improves response delivery in the native macOS app and compatible
coding clients.

- Streams ordinary answer text when tools are available instead of waiting for
  the entire generation to finish.
- Preserves chronological reasoning, text, and tool-call blocks across native,
  Anthropic, OpenAI Chat Completions, and Responses APIs.
- Fixes relay buffering that could delay the first visible event.
- Reduces macOS chat rendering overhead while preserving the first and final
  streamed text.
- Reports client-visible first-output latency in the app, including model load
  and queue time that occurs during generation.
- Adds regression coverage for fragmented streams, first-word preservation,
  multiple tool calls, cancellation, and concurrent clients.
- Adds reproducible delivery benchmarks and documents remaining cold-start and
  queue limitations.

An experimental MLX prefill-checkpoint path is included for research but remains
disabled by default because it did not preserve exact output in every test.
