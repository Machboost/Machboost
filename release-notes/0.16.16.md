# MachBoost 0.16.16

Corrects the MachBoost menu-bar logo's intrinsic dimensions so macOS displays it
at the intended size. The logo uses native template rendering for light and dark
menu bars.

Includes the 0.16.15 streaming fixes for the native app and compatible coding
clients: immediate prose delivery with tools enabled, chronological reasoning
and tool events, relay buffering fixes, and client-visible first-output timing.

The community DMG is ad-hoc signed, not Apple-notarized. Existing installations
can download, verify, install, and relaunch through the signed Sparkle update feed.
