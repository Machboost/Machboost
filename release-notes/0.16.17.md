# MachBoost 0.16.17

Refines the native chat controls and navigation:

- Aligns Dev mode, permission selection, and connector controls with consistent
  spacing and click targets. Permissions remain directly beside Dev mode.
- Distinguishes inference device selection from local/paid API routing.
- Moves the workspace changes toggle to the far right of the chat toolbar and
  uses a document-review icon.
- Places conversation history above workspace navigation in the sidebar.
- Moves reasoning effort into the composer with a stepped slider, model label,
  reset action, and reasoning visibility control. The selector is hidden for
  models without reasoning support and for paid-first routes whose model
  capabilities are not known locally. Muse Glimmer does not offer an Off setting.
- Retains the corrected native MachBoost menu-bar logo from 0.16.16.

Includes the 0.16.15 streaming improvements. Inference behavior and permission
policies are unchanged by this UI update.

Validation: 22 macOS UI tests, 100 Swift unit tests, 605 Python tests, and the Go
suite passed. The Release app built successfully. A production app smoke test
completed a repository tool call, but a later interaction became unresponsive.
That issue remains under investigation; this release does not claim to fix
long-running generation or all empty-response cases.

The community DMG is ad-hoc signed, not Apple-notarized. Existing installations
can update through Sparkle without downloading manually.
