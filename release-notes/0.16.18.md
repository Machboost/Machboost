# MachBoost 0.16.18

This maintenance release refreshes the macOS distribution without changing inference behavior.

- Rebuilds the installer with organization-owned update URLs and package metadata.
- Omits local installation-source metadata and build-time Python bytecode from the bundled runtime.
- Updates the recommended package installation commands.

Existing model downloads, conversations, and settings remain compatible. The community macOS build remains ad-hoc signed rather than Apple-notarized.
