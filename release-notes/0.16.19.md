# MachBoost 0.16.19

- Interactive CLI chat starts with Low reasoning for models that report reasoning support. Explicit Off and effort overrides remain available.
- Removes the default 128-token output ceiling from run, chat, code, and completion commands. Use `--max-tokens N` to set a cap or `--max-tokens -1` for no separate output cap. EOS, cancellation, and model context boundaries still apply.
- The desktop reasoning selector defaults to Low for reasoning-capable models. Saved explicit preferences remain unchanged; Reset restores the model-aware default.
- Reasoning-only replies no longer automatically blame an output cap when no cap was reached.
- Adds a reproducible HTTP benchmark that distinguishes first reasoning output from the first answer text.

These are generation-default corrections, not a new inference algorithm. Reasoning can increase time to the final answer. The community application remains ad-hoc signed, not Apple-notarized.
