# MachBoost 0.16.20

- Adds PyPI Trusted Publishing with protected environment approval, artifact checks, and clean-install verification.
- Publishes package metadata linking to the project website, documentation, source, and issue tracker.
- Bounds optional MLX dependencies to the tested minor-version families so fresh installs do not silently select an unvalidated native backend release.
- Keeps model weights, local data, research artifacts, and the bundled desktop runtime out of Python distributions.

This is a packaging release; inference behavior is unchanged from 0.16.19.
The native app remains available separately as a community DMG, ad-hoc signed
and not Apple-notarized.
