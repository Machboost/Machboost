# MachBoost 0.16.21

This patch fixes multimodal routing for cached MLX models whose repository names do not contain a vision marker.

- Detects vision support from cached model configuration and loads Gemma 4 MLX conversions through `mlx-vlm`.
- Validates image attachments against the model catalog for the selected inference device.
- Removes the misleading universal Max reasoning tier from the macOS app. Effort controls remain conservative hints because some models expose only an on/off thinking switch.
- Clarifies that GIF attachments currently use their first frame rather than temporal animation decoding.
