# MachBoost 0.16.22

This release hardens local models used through Claude Desktop and Claude Code.

- Stops unchanged successful tool calls from repeating indefinitely.
- Forces a final recovery answer from existing tool results when a loop is detected.
- Hides Gemma and Muse internal `<|tool_response>` and `<turn|>` protocol markers.
- Adds fragmented-stream coverage for control tokens and Anthropic tool-loop recovery.

The loop guard is deliberately narrow: different tools and changed arguments remain
available for normal multi-step agent work.
