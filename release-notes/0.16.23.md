# MachBoost 0.16.23

This patch fixes connected MCP tools and long-chat rendering in the macOS app.

- Accepts standard `Header: value` syntax as well as `Header=value` when configuring MCP HTTP headers.
- Reports malformed connector fields before saving instead of silently discarding them.
- Preserves stored connector secrets when editing redacted configurations.
- Executes discovered MCP tools when a model returns nested arguments as JSON text, including tools with no arguments.
- Keeps chat rows rendered while scrolling so long or streamed conversations do not blank and reload.
- Adds full app coverage for MCP discovery, approval, invocation, final responses, and repeated transcript scrolling.
