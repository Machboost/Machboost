# MachBoost 0.16.24

This release connects MachBoost to coding clients and makes local and shared
inference use one resident runtime.

- Adds verified launch and configuration flows for Codex CLI and ChatGPT Desktop,
  with OpenAI Responses API compatibility and native app controls.
- Adds preview Claude Desktop and Claude Code gateway integration, including
  compatibility fixes for reasoning, tool calls, and streamed responses.
- Distributes simultaneous app and CLI requests across eligible warm hosts using
  live latency, replica, active-request, queue, and reservation signals.
- Shares connected-host profiles and protected credentials between the macOS app
  and CLI while continuing to use one local daemon, model cache, and queue.
- Wakes a matching installed MachBoost app before a local CLI command starts a
  headless resident daemon.
- Adds JSON and JSON Schema output to the native CLI, OpenAI Chat Completions,
  OpenAI Responses, and the existing Ollama-compatible API.
- Improves the Apps experience with recognizable client icons, host-aware setup,
  and clearer support labels.

Load balancing applies to independent concurrent requests when more than one
eligible host has the requested model available. It does not split a single token
stream across machines, and failover stops once response output has been emitted.
