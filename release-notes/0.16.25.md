# MachBoost 0.16.25

This hotfix restores Codex and ChatGPT Desktop startup with generated MachBoost
model catalogs.

- Stops writing JSON `null` values for typed Codex model catalog fields.
- Supplies valid defaults for reasoning, verbosity, patch, and web-search tool
  descriptors.
- Prefers the working Codex executable bundled with ChatGPT on macOS before a
  stale or incomplete executable found on `PATH`.
- Adds regression coverage for plain and reasoning-capable model entries.
