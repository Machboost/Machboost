# MachBoost 0.16.26

## Fixes and improvements

- ChatGPT/Codex desktop setup uses a credential relay and an HTTP Responses provider to avoid the unauthenticated WebSocket connection.
- Preserve tool-call IDs, tool results, and names through the vision-model prompt path, fixing a reproduced repeated-tool loop with Gemma.
- CLI coding sessions show tool output and edit previews. Use `/changes` for this session's file-tool edits and `/diff` for the complete Git working tree.
- Shell failures and timeouts report errors with captured output instead of appearing successful.
- Native app edit previews show full-file context and actual line numbers.

## Verification

The bundled-runtime Python suite ran 660 tests with 5 skipped and no failures; 104 native macOS unit tests passed. In a local Gemma coding fixture, the patched model read files, corrected a function, and passed an independently rerun test. This is a functional result, not a general inference-speed claim. The native GUI workflow was not manually exercised for these changes.

## Installation

Apple Silicon, macOS 14 or later. This community build is ad-hoc signed, not Apple-notarized. After a blocked first launch, use System Settings > Privacy & Security > Open Anyway only after verifying you downloaded the official release. The update feed is signed for in-app updates.
