# MachBoost 0.16.27

## Fixes and improvements

- Accept Anthropic `x-api-key` authentication as well as bearer tokens, using the same team permissions. This fixes a reproduced Claude Code retry loop that ended in HTTP 401 before inference started.
- Decode bounded gzip and zstd request bodies from coding clients. Codex integration uses HTTP Responses streaming instead of the unsupported WebSocket transport.
- Support MachBoost-owned Responses compaction, retaining recent messages and tool state. Foreign or damaged compacted history returns recovery guidance instead of silently dropping history.
- Include measured input-token usage in the final Anthropic streaming event and avoid empty trailing reasoning blocks.
- Preserve direct CLI conversation cache affinity, isolate unrelated sessions, rotate the cache key on `/clear`, and forward the selected reasoning strength.
- Filter split Gemma turn delimiters without removing ordinary response text.
- Add `machboost start` for explicit resident-server startup, including bundled-runtime startup over SSH without requiring the desktop window.
- Separate first model output from first answer text in latency reports. Benchmark invocations use fresh IDs and report queue time and cached prompt tokens.
- Remove an unvalidated automatic VLM prefill override; retain native backend defaults unless explicitly configured.

## Performance and verification

The controlled [latency audit](https://github.com/Machboost/Machboost/blob/v0.16.27/docs/latency-audit-20260921.md) includes same-model native MLX-VLM comparisons, the installed Mac app, and actual Claude Code CLI tasks. Reusing a prompt prefix reduced follow-up latency substantially in those fixtures, but did not demonstrate a general generation-speed gain. Cached follow-up token sequences differed from the uncached baseline; these results are not a claim of universal speedup or identical output.

The pre-release Python suite ran 687 tests with five optional tests skipped and no failures; Go tests passed. The regular installed app produced complete streamed responses, and Claude Code completed a read-only file task. Claude Desktop and Codex desktop were not manually retested for this release. CI additionally checks Python packaging and the native macOS app.

EXO and multi-Mac model sharding are not included in this release.

## Installation

Update the Python package with `python -m pip install --upgrade machboost`, retaining any backend extras you use, such as `"machboost[mlx]"`.

The DMG requires Apple Silicon and macOS 14 or later. This community build is ad-hoc signed, not Apple-notarized. After a blocked first launch, use System Settings > Privacy & Security > Open Anyway only after verifying you downloaded the official release. The update feed is signed for in-app updates.
