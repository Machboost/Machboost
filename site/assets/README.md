# Site assets

- `machboost-mark.svg` and `machboost-icon.png`: MachBoost identity assets.
- `machboost-coding.webp`: unretouched application-window capture from the
  `testCodingAgentShowsMultiRoundActivityAndReviewableChanges` UI test on
  September 6, 2026, using sample data. Converted to WebP for the website.
  This is a UI preview, not a model-quality or performance measurement.
- `machboost-network.webp`: generated hardware illustration, created with the
  built-in image-generation tool. It illustrates separate networked computers,
  not combined GPU memory or a hardware product sold by MachBoost.
- `geist-latin.woff2`: Geist Latin variable font from
  `@fontsource-variable/geist` 5.2.6. License: `geist-LICENSE`.
- `lucide.min.js`: Lucide 0.468.0 UMD bundle. License: `lucide-LICENSE`.

The generated illustration used this brief: a wide, photoreal editorial studio
image on pale cool mint, with a silver desktop computer and two closed laptops
in the lower half, joined by a green braided cable. Keep the upper half empty
for website copy. Use crisp brushed-aluminum detail and soft daylight shadows;
include no text, people, floating objects, or performance figures.

Fonts and icons are served from this site, without third-party CDN requests.
