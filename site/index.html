machboost pull qwen2.5:3b

machboost serve

The Mac app includes its runtime. This CLI install uses your Python environment.

Python / OpenAI SDK 
import os
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:11435/v1",
    api_key=os.environ["MACHBOOST_API_KEY"],
)

for chunk in client.chat.completions.create(
    model="qwen2.5:3b",
    messages=[{"role": "user", "content": "Hello!"}],
    stream=True,
):
    if chunk.choices:
        print(chunk.choices[0].delta.content or "",
              end="", flush=True)

Install the OpenAI SDK, load the model, and set your host's key. Use its LAN endpoint for a shared Mac.

BEFORE YOU MAKE YOURSELF AT HOME

Good questions.
Straight answers.

Ask on GitHub
Is it faster for every prompt?

No. The strongest measured gains come from useful reusable context. A fresh question may run at native backend speed, and the server can add overhead. Benchmarks name the workload, model, cache state, and limitations.

Do I need Ollama or Python?

The Mac app includes its Python and MLX runtime. No separate Python installation or Ollama is needed for native models. The standalone CLI requires Python and the matching backend extras.

Can other computers use my Mac's models?

Yes. Enable authenticated LAN serving on the host, then connect with its address and a scoped key. MachBoost clients can use saved hosts; other tools can use a compatible API. Serving shares inference, not the machines' GPU memory.

Which models and file types work?

The desktop app supports compatible MLX text and MLX-VLM vision repositories. Reasoning, tool calls, and visual inputs depend on the model and backend. Attach plain text, source code, folders of text/code, and supported images. Check model capabilities before downloading.

Does anything leave my Mac?

Local inference and chats stay on your Mac. Shared hosts and paid-provider fallback receive requests you send to them. MCP connectors follow their service behavior. Downloads and update checks contact their providers. MachBoost does not upload telemetry.

Why does macOS block the first launch?

The community build is ad-hoc signed and isn't Apple-notarized. After the first blocked launch, use System Settings → Privacy & Security → Open Anyway. Verify the release checksum first. Supported installations use a signed Sparkle update feed.
